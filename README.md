# Mphatso Mphepo - Professional Portfolio

A modern, responsive portfolio website showcasing the professional experience, skills, and projects of Mphatso Mphepo, an ICT and Data Science Professional specializing in Core Banking & Process Automation.

## Features

- **Modern Design**: Clean, Google-inspired minimalist design with professional blue color scheme
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Scroll-reveal animations and interactive hover effects
- **Comprehensive Sections**:
  - Hero section with professional title and call-to-action buttons
  - About Me with professional summary
  - Skills categorized into Technical and Professional competencies
  - Experience timeline with work history and leadership roles
  - Projects showcase with interactive cards
  - Education background
  - Professional certifications
  - Achievements and recognition
  - Testimonials (with LinkedIn integration)
  - Contact form with validation
- **Download CV**: Direct CV download functionality
- **Social Integration**: LinkedIn and GitHub profile links

## Tech Stack

- **React.js 19**: Modern functional components with hooks
- **Vite**: Fast build tool and development server
- **Tailwind CSS 4**: Utility-first CSS framework
- **PostCSS**: CSS processing
